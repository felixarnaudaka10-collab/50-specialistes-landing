📖 Guide d'installation

Tes 70 Spécialistes IA opérationnels en moins de 3 minutes

1Télécharge ton Kit

Depuis la page de confirmation d'achat, clique sur "📦 Télécharger mon Kit". Tu obtiens un fichier ZIP — ne le décompresse pas, garde-le tel quel.

2Ouvre l'application Claude

Il te faut l'application Claude sur ordinateur (Mac ou Windows), téléchargeable gratuitement sur claude.ai/download. Un compte Claude est nécessaire (Claude Pro recommandé).

3Installe le plugin

Ouvre une session Cowork dans l'application Claude, puis :

  • Glisse-dépose le fichier ZIP directement dans la fenêtre de conversation
  • Demande à Claude : Installe ce plugin
  • Claude te propose l'installation → confirme

Alternative : Paramètres → Capacités → ajouter le plugin manuellement.

4Vérifie et utilise

Écris à Claude : Liste mes spécialistes disponibles — tes 70 spécialistes doivent apparaître. Pour en utiliser un : Utilise Hugo le copywriter pour rédiger ma page de vente. C'est tout.
